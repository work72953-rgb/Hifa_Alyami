# Haifa Al-Yami Portfolio

Arabic portfolio built with Next.js App Router, JavaScript, and Tailwind CSS v4.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure

- `app/`: routes
- `components/`: reusable UI
- `data/`: profile/navigation/work metadata
- `public/works/`: source portfolio files from the supplied archive

To add or edit work items, update `data/works.js` only.
